Flashcards de Estudo: Tipos de Motos

Use os cards abaixo para estudar os principais tipos de motocicletas. Utilize a tecla TAB para navegar entre os elementos.

Street / Naked

Pergunta: Qual é a principal característica das motos Street e Naked?

Mostrar Resposta

Resposta: São voltadas para o uso urbano diário. Oferecem posição de pilotagem ereta e confortável, sendo que as Nakeds não possuem carenagem para expor o motor.

Custom / Cruiser

Pergunta: Para qual tipo de uso as motos Custom são projetadas?

Mostrar Resposta

Resposta: Focadas em viagens longas e estradas. Têm assento baixo, pedaleiras avançadas e posição de pilotagem relaxada.

Trail / Big Trail

Pergunta: Qual é o diferencial das motos da categoria Trail?

Mostrar Resposta

Resposta: Possuem suspensão de longo curso e posição alta, sendo ideais para uso misto (asfalto e terra/off-road).

Esportiva (Sport)

Pergunta: Qual é o foco principal do design de uma moto Esportiva?

Mostrar Resposta

Resposta: Priorizam aerodinâmica e alto desempenho. O piloto anda inclinado para a frente e a moto possui carenagens completas.
