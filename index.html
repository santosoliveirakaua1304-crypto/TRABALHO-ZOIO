Flashcards: Acessibilidade Web (a11y)

Utilize a tecla Tab para navegar entre os cartões e a tecla Espaço ou Enter para revelar a resposta.

  • Pergunta 1

    O que é o atributo alt em uma imagem?

    Resposta: É o texto alternativo usado por leitores de tela para descrever a imagem a pessoas com deficiência visual.

  • Pergunta 2

    Por que o foco visível (:focus-visible) é essencial?

    Resposta: Permite que usuários que navegam pelo teclado saibam exatamente qual elemento está selecionado no momento.

  • Pergunta 3

    O que significa a sigla WCAG?

    Resposta: Web Content Accessibility Guidelines (Diretrizes de Acessibilidade para Conteúdo Web).
